# led-detector

HSV色空間を使ったLED異常検出ライブラリ．画像内のピクセルをRGB→HSV変換し，正常なLEDの色範囲外のピクセル率から異常を判定する．


## 使い方
```bash
cargo run
```

## 出力例
```
ファイル: ./images/green.png
異常ピクセル率: 24.5%
判定: 正常

ファイル: ./images/red.png
異常ピクセル率: 100.0%
判定: 異常あり
```

## ベンチマーク結果
```
serial   :   3.4 µs
parallel : 820.0 µs
```

小さい画像ではスレッド起動コストが処理コストを上回るため直列処理の方が速い。
大きい画像（4K等）では並列処理が効果を発揮する。
```bash
cargo bench
```

## アルゴリズム概要

1. 画像ファイルを読み込む
2. 各ピクセルのRGB値をHSV色空間に変換
3. HSV値が正常範囲内かどうかを判定
4. 異常ピクセル率が50%を超えた場合「異常あり」と判定

## 使用クレート

- `image`: 画像ファイルの読み込み・ピクセル操作
- `rayon`: 並列ピクセル処理
- `criterion`: 直列・並列処理のベンチマーク

## 学んだこと

- `trait`と`impl ~ for`による抽象化（C#のinterfaceに相当）
- `rayon`による並列イテレータ（`par_bridge()`）
- `Send + Sync`トレイト境界とスレッド安全性
- `criterion`を使ったベンチマーク計測
- `lib.rs`によるライブラリ設計と`pub`による公開
- 並列処理が効果を発揮する条件（データ量とスレッド起動コストのトレードオフ）
